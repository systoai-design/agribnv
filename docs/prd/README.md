## PRD Schema Quality Standards
Each PRD in this directory adheres to the schema defined in `.agents/skills/prd/SKILL.md`:
1. **Executive Summary:** Problem statement, proposed solution, and measurable success criteria.
2. **User Experience & Functionality:** User personas, user stories (`As a [user]...`), concrete acceptance criteria (`AC-*`), and explicit non-goals.
3. **Architecture & Domain Models:** Mermaid ER and sequence diagrams illustrating entity relationships and execution flows.
4. **Technical Specifications:** Database schemas, API endpoints, RLS security policies, and performance budgets.
5. **Risks & Phased Roadmap:** Phased milestones and technical failure-mode mitigations.
